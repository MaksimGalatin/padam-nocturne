# PADAM · NOCTURNE Studio — Настольное приложение и установщик Windows (Г7 + Г8 + 14.3)

Настольное приложение **PADAM · NOCTURNE Studio** с каноническим векторным логотипом **CODE («две фигуры»)**, собственным окном без браузера и адресной строки (системный WebView2), значком в системном трее, нативными уведомлениями Windows при удержании подозрительных записей агента и встроенной средой Python 3.14.4 внутри установщика.

---

## 1. Установщик Windows `PADAM-Studio-Setup.exe` (Tauri v2 + NSIS)

Собранный установщик (`20,97 МБ`, `21 987 283` байт) предоставляет привычную установку настольной программы на ПК без использования командной строки:

1. **Мастер установки в два шага:** выбор языка интерфейса (русский, английский, испанский, китайский) и папки установки, создание ярлыков **«PADAM Studio»** с нашей иконкой CODE на **Рабочем столе** и в **меню «Пуск»**, регистрация в системном списке **«Установка и удаление программ»** (`PADAM Studio v0.2.0`, издатель `CODE Eternal LLC (Maksim Galatin)`) и чистое удаление через `uninstall.exe`.
2. **Собственное окно Studio (WebView2):** открывается в отдельном нативном окне без вкладок браузера и адресной строки, запоминает размер и положение на экране в `%LOCALAPPDATA%\PADAM Studio\window-state.json` (холодный старт — `1,24 с`).
3. **Встроенный Python 3.14.4 (`runtime/python.exe`):** приложение включает официальный интерпретатор Python 3.14.4 (`python-3.14.4-embed-amd64`), колёса `numpy`, `requests`, `cryptography` и пакет `padam` в открытой папке `runtime/` — пользователю не нужно устанавливать Python, Git или Visual Studio.
4. **Почему открытая папка `runtime/`, а не `PyInstaller --onefile`:** упаковщик `PyInstaller --onefile` склеивает интерпретатор и библиотеки в один `.exe`, который при каждом запуске распаковывает исполняемые `.dll`/`.pyd` во временную папку `%TEMP%\_MEI*`. Такое поведение совпадает с поведением упаковщиков вредоносных программ и вызывает ложные срабатывания эвристики (`IDP.Generic` в AVG/Avast). Официальный подписанный `runtime/python.exe` в открытой папке установки работает без самораспаковки в `Temp` и не вызывает срабатываний антивируса.
5. **Системный трей с логотипом CODE:** при нажатии на крестик `[X]` окно не убивает защиту памяти, а сворачивается в область уведомлений (трей). Меню значка в трее содержит:
   - **«На проверке: N»** — живой счётчик записей агентов, удерживаемых на проверке (клик сразу открывает окно Studio на вкладке «На проверке»);
   - **«Открыть PADAM Studio»** — разворачивает главное окно;
   - **«Сон NOCTURNE»** — запускает цикл консолидации памяти;
   - **«Выход»** — штатно останавливает локальный сервер и закрывает приложение.
6. **Нативные уведомления Windows (`Г8`):** когда агент пытается записать текст, похожий на скрытый приказ (инъекцию) или затрагивающий защищённые записи, и запись попадает в очередь «На проверку», приложение отправляет системное уведомление Windows (WinRT Toast):
   > **PADAM · NOCTURNE Studio**  
   > *Агент хотел записать похожее на приказ — проверь (на проверке: N)*
7. **Автозапуск по выбору владельца:** на вкладке **«Настройки»** в Studio добавлена галочка **«Запускать при входе в Windows (в трее)»** (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PADAMStudio`, запускает приложение с флагом `--minimized`). По умолчанию автозапуск **выключен** — программа ничего не прописывает в автозагрузку без решения человека.

## 2. Честное примечание о Windows SmartScreen и подписи кода (`14.3`)

Проект сознательно не приобретает коммерческий сертификат подписи кода (Microsoft Authenticode OV/EV) на текущем этапе:

- **Что увидит пользователь при первом запуске скачанного установщика:** поскольку `PADAM-Studio-Setup.exe` пока не подписан платным сертификатом Authenticode, фильтр **Windows SmartScreen** при первом запуске файла из интернета покажет стандартное синее окно предупреждения *«Система Windows защитила ваш компьютер»*. Чтобы продолжить установку, нажмите **«Подробнее» → «Выполнить в любом случае»** (*More info → Run anyway*).
- **Готовность сборочного конвейера к подписи:** шаг цифровой подписи `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256` уже встроен в `desktop/build_windows_installer.ps1` и автоматически активируется при наличии переменной окружения `PADAM_SIGN_PFX`.
- **Локальная антивирусная проверка:** на рабочей машине сборка и установка проверены при активном антивирусе **AVG Antivirus** (который ранее блокировал старый прототип `.exe`-дроппера как `IDP.Generic`; новый установщик Tauri v2 + открытый `runtime/python.exe` проходит установку, запуск и удаление без единого предупреждения AVG). Штатный Windows Defender на этой машине отключён системно, так как управление защитой передано активному AVG.

## 3. Воспроизводимая сборка установщика с нуля

Сборка выполняется одной командой без установки Visual Studio на системный диск `C:` (использует портативный Rust + `cargo-xwin` + LLVM `llvm-rc.exe` и официальный дистрибутив Python 3.14.4 embed):

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build_windows_installer.ps1
```

Дополнительно доступен легковесный режим `python -m padam desktop` (`padam/desktop.py`) для систем, где пакет установлен через `pip` / `uvx`.
