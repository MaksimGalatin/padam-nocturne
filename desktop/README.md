# PADAM · NOCTURNE Studio — Настольное приложение (Desktop & System Tray)

Настольная оболочка для **PADAM Studio** без встроенного Chromium (не раздувает установку до 150+ МБ, как Electron) и без самописных `.exe`-загрузчиков, вызывающих ложные срабатывания антивирусов.

## 1. Штатный запуск без неподписанных `.exe` (рекомендуется)

Пакет включает встроенный настольный центр памяти **`padam desktop`** (`padam/desktop.py`), который работает внутри официального подписанного интерпретатора Python (`python` / `pythonw` / `uvx`):

```bash
# Запуск настольного окна центра памяти и локального сервера Studio в одном процессе:
uvx padam-nocturne desktop
# или из установленного пакета:
python -m padam desktop

# Создание ярлыка запуска на рабочем столе или в выбранной папке:
python -m padam desktop --create-shortcut "~/Desktop"
```

### Почему это безопасно и не блокируется антивирусами (`IDP.Generic`):
- **Никаких `.exe`-дропперов с `base64` в `AppData`:** не создаёт и не распаковывает исполняемые бинарники на лету.
- **Никакого скрытого запуска дочерних процессов (`CreateNoWindow`):** сервер `make_studio_server` запускается в потоке `threading.Thread` того же процесса.
- **Токен не передаётся в командной строке (`--token`):** секретный токен хранится в памяти процесса и в переменной окружения `PADAM_API_TOKEN`, поэтому он не виден другим процессам через список процессов ОС.
- **Никаких зашитых путей и версий браузера:** использует установленный в `PATH` / `venv` пакет `padam` и открывает системный браузер по умолчанию (`webbrowser.open`).

## 2. Нативная сборка Tauri v2 (`desktop/tauri/`)

Для сборки платформенных пакетов (`.msi` / NSIS под Windows, `.dmg` под macOS, `.deb` / `.AppImage` под Linux) на машине с установленным инструментарием Rust (`rustc` + `cargo`):

```bash
cd desktop/tauri
cargo tauri build
```

> **Честное примечание о подписи кода:** проект не использует платные сертификаты подписи кода (Microsoft Authenticode / Apple Developer ID). При сборке собственного `.msi` / `.exe` через Tauri без платного сертификата Windows SmartScreen и антивирусы могут показывать стандартное предупреждение для неподписанных программ.
