## 2. Что можно и что нельзя по Лицензии PADAM 1.0

| Действие | Можно? |
|---|---|
| Скачать, установить, пользоваться памятью, защитой, Studio — дома или в компании | Да, бесплатно |
| Пользоваться Заработком (заказы, магазины, партнёрка, Мастер платформ, Рой, Автопилот) | Да, с комиссией 15 % / 20 % с каждой оплаты клиента |
| Читать код, менять его для себя | Да |
| Давать другим **неизменённые** копии бесплатно, вместе с лицензией | Да |
| Вырезать, отключать или подделывать расчёт комиссии, её журнал, маршрут оплаты, окно согласия | Нет |
| Раздавать, продавать, публиковать **изменённые** копии | Нет — только по отдельной коммерческой лицензии |
| Сдавать PADAM другим как сервис, перепродавать, сублицензировать, встраивать в свой продукт | Нет — только по отдельной коммерческой лицензии |
| Делать на его коде конкурирующий продукт | Нет |

Согласие: в Studio и при установке — окно с тремя галочками (лицензия, комиссия, запрет обхода), квитанция согласия
подписывается и хранится в базе; в командной строке — флаг `--accept-terms`.
