PADAM · NOCTURNE — память, которая сторожит себя сама

Локальная трёхуровневая память для ИИ-агентов в одном SQLite-файле: маскирует секреты и кошельки до диска, удерживает подозрительные приказы на решение владельца, отделяет подтверждение факта от показа и умеет стирать одну запись криптографическим уничтожением ключа.

0 $ и 0 внешних вызовов

Базовый поиск объединяет слова (BM25), точные идентификаторы и локальный фоллбэк без платных API и интернета.

97.0 % / 99.2 % LongMemEval-S · LoCoMo 91.1 % / 95.8 %

LongMemEval-S (470 с ответом): any@5 — 97.0 %, any@10 — 99.2 %, all@10 — 93.0 %. LoCoMo (10 диалогов, 1 536 с ответом): sess_any@5 — 90.1 % (91.1 % с PADAM_RERANK=1), sess_any@10 — 95.5 % (95.8 %).

30 000 фейковых ключей -> 0 утечек

До записи на диск маскируются 20+ форматов ключей API, кошельки Solana (id.json, base58, сид-фразы) и карты по Луну.

Стирание одной записи + квитанция

У каждой записи свой ключ AES-256-GCM. Команда forget уничтожает ключ и выдаёт проверяемую квитанцию JSON/HTML.

Три уровня памяти (L1 -> L2 -> L3)

L1 — рабочая память

Текущий диалог и буфер эпизодов (padam log). Принимает сырые события без засорения долгосрочных фактов.

L2 — консолидированный SQLite

7 видов записей, два независимых часа (last_seen_at и last_confirmed_at), версионность, очередь проверки и гибридный поиск FTS5 + векторы.

L3 — вечный проверяемый слой

Необязательный слой: шифротекст каждой записи в Arweave (Turbo), корень Меркла в Solana Memo и штамп времени в Bitcoin (OpenTimestamps).
