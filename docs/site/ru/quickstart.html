Быстрый старт и PADAM Studio

От нулевой установки до живого 10-экранного веб-интерфейса на демо-базе и подключения ко всем основным ИИ-клиентам.

Установка (выберите нужный набор)

pip install padam-nocturne
# or with local model2vec embeddings (~30 MB):
pip install "padam-nocturne[embed]"
# optional L3 anchoring & ONNX injection detector:
pip install "padam-nocturne[l3,guard]"

Первый запуск на демо-памяти (основная база не затрагивается)

Команда python -m padam demo --studio создаёт изолированную ~/.padam/demo.db с подписанными предпочтениями, цепочкой версий, графом выводов, удержанной инъекцией, снимком L3 и выданной квитанцией удаления.

python -m padam demo --studio
# quick CLI tour:
python -m padam remember "Answer in Russian, numbers first" --kind preference --importance 1.0
python -m padam recall "which language to use" --explain
python -m padam doctor

Подключение к ИИ-агентам в один клик и SDK

claude mcp add padam -- uvx padam-nocturne
# Multilingual Russian/Spanish/Chinese memory:
claude mcp add padam -e PADAM_EMBEDDER=model2vec -e PADAM_LOCAL_EMBED_MODEL=minishlab/potion-multilingual-128M -- uvx --from "padam-nocturne[embed]" padam-nocturne

MCP для Claude Code / Cursor / Codex / Gemini CLI / Antigravity

Готовые манифесты плагинов в репозитории (.claude-plugin/, plugins/cursor, plugins/codex, plugins/gemini-cli, plugins/antigravity) со скиллом и командами /recall, /remember, /profile.

LangChain, CrewAI, Vercel AI и Mastra

Готовые обёртки в integrations/ (Python) и официальный TypeScript SDK packages/padam-client/ с экспортом инструментов для Vercel AI SDK и Mastra.

Настольное приложение и расширение браузера

python -m padam desktop открывает локальный центр памяти без встроенного Chromium (и проект Tauri desktop-tauri/); расширение browser-extension сохраняет выделенный текст как origin=external.

Что внутри 10 экранов PADAM Studio

  • Обзор + Доктор безопасности (светофор настроек, права файла БД, целостность PRAGMA quick_check).
  • Лента памяти, Поиск --explain (разложение баллов rrf x imp x conf x decay) и Машина времени as_of.
  • Очередь проверки (Approve / Reject), Забыть + квитанции удаления, Граф связей <canvas>, Вечный слой L3, Настройки и Быстрый старт.
  • Строгий CSP с одноразовыми nonce, 0 innerHTML (строго textContent), токен в #t= стирается через history.replaceState, 4 языка и 2 темы.
