Configuration environment variables

VariableDefaultMeaning
PADAM_DB~/.padam/memory.dbSQLite database path
PADAM_USERdefaultOwner identifier inside SQLite
PADAM_LANGsystemCLI output language: en or ru
PADAM_STRICT01: hold every agent write, ignore unsafe bypasses, require passphrase for L3 and token for REST
PADAM_MCP_REVIEW_ALL01: hold all MCP writes for owner review regardless of claimed origin
PADAM_HOLD_EXTERNAL11: hold every write marked origin=external regardless of wording
PADAM_MASK_PII01: additionally mask emails and phone numbers before writing to disk
PADAM_KEEP_SECRETS01: store secrets unmasked (disabled automatically under PADAM_STRICT=1)
PADAM_EMBEDDERautoauto, builtin, ollama, model2vec, or fastembed
PADAM_LOCAL_EMBED_MODEL—Hugging Face or local path, e.g. minishlab/potion-multilingual-128M
PADAM_SEARCH_FEEDBACK11: second local search pass with feedback terms; 0 disables
PADAM_RERANK01: re-score top search candidates by term coverage, proximity span, bigrams (or local ONNX model); 0 by default
PADAM_RERANK_TOP30Maximum number of top candidates passed to the reranker when PADAM_RERANK=1
PADAM_RERANK_MODEL—Optional directory with local ONNX cross-encoder (tokenizer.json + .onnx)
PADAM_GUARD_MODEL—Path to optional ONNX prompt-injection classifier ([guard], off by default)
