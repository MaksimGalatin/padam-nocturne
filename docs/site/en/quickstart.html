Quick Start & PADAM Studio

Go from zero to an interactive 10-screen local UI on an isolated demo database and one-click plugins across AI clients.

Installation options

pip install padam-nocturne
# or with local model2vec embeddings (~30 MB):
pip install "padam-nocturne[embed]"
# optional L3 anchoring & ONNX injection detector:
pip install "padam-nocturne[l3,guard]"

Try on isolated demo memory (never touches memory.db)

python -m padam demo --studio populates ~/.padam/demo.db with signed preferences, version chains, derived lineage, held prompt injections, a local L3 anchor and an issued Forget Receipt.

python -m padam demo --studio
# quick CLI tour:
python -m padam remember "Answer in Russian, numbers first" --kind preference --importance 1.0
python -m padam recall "which language to use" --explain
python -m padam doctor

AI clients, plugins & SDKs

claude mcp add padam -- uvx padam-nocturne
# Multilingual Russian/Spanish/Chinese memory:
claude mcp add padam -e PADAM_EMBEDDER=model2vec -e PADAM_LOCAL_EMBED_MODEL=minishlab/potion-multilingual-128M -- uvx --from "padam-nocturne[embed]" padam-nocturne

One-click plugins (Claude Code, Cursor, Codex, Gemini CLI, Antigravity)

Ready-to-enable manifests in .claude-plugin/, plugins/cursor, plugins/codex, plugins/gemini-cli and plugins/antigravity with /recall, /remember, /profile commands.

LangChain, CrewAI, Vercel AI & Mastra

Python wrappers under integrations/ and TypeScript SDK packages/padam-client/ exporting Vercel AI and Mastra tools.

Windows Desktop Installer (Tauri v2) & browser extension

PADAM-Studio-Setup.exe (desktop/tauri/, 20.97 MB, bundled Python 3.14.4 runtime/, system tray, Windows Toast notifications on held writes; unsigned with paid Authenticode — on first run in SmartScreen click More info -> Run anyway) plus python -m padam desktop; browser-extension forces Origin chrome-extension:// to external.

Inside PADAM Studio (10 screens)

  • Overview & Security Doctor (weak switches, SQLite quick_check, key protection status, REST token status).
  • Memory Feed, Search --explain (rrf x imp x conf x decay breakdown) and Time Machine (as_of).
  • Review Queue (Approve/Reject), Forget + downloadable JSON/HTML receipts, Canvas Lineage Graph, L3 Anchor & Settings.
  • Strict nonce CSP, zero innerHTML (textContent only), fragment token stripped via history.replaceState, 4 languages and 2 themes.
