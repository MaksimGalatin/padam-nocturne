PADAM · NOCTURNE — memoria que se protege a sí misma

Memoria local de tres niveles en un único archivo SQLite: enmascara claves API y billeteras Solana antes de escribir en disco, retiene órdenes ocultas para revisión del propietario, separa el reloj de consulta del reloj de confirmación y borra registros individuales destruyendo su clave AES-256-GCM.

$0 por escritura, 0 llamadas cloud

La búsqueda híbrida combina BM25, identificadores exactos y respaldo vectorial local sin APIs de pago.

97.0 % / 99.2 % LongMemEval-S · LoCoMo 91.1 % / 95.8 %

LongMemEval-S (470 con respuesta): 97.0 % any@5, 99.2 % any@10, 93.0 % all@10. LoCoMo (10 chats, 1,536 preguntas): 90.1 % sess_any@5 (91.1 % con PADAM_RERANK=1), 95.5 % sess_any@10 (95.8 %).

0 de 30 000 claves falsas filtradas

Más de 20 formatos de secretos, llaves/frases Solana (conservando la dirección pública) y tarjetas Luhn se ocultan antes de SQLite.

Olvido criptográfico por registro

Cada registro tiene su propia clave AES-256-GCM. padam forget la destruye y emite un recibo JSON/HTML.

Tres capas, una sola memoria (L1 -> L2 -> L3)

L1 — memoria de trabajo

Conversación actual y búfer de episodios (padam log) sin contaminar hechos verificados.

L2 — SQLite consolidado

7 tipos de registros, dos relojes independientes (last_seen_at y last_confirmed_at), historial de versiones y búsqueda híbrida.

L3 — capa eterna verificable

Opcional: lotes cifrados en Arweave (Turbo), raíz de Merkle en Solana Memo y sello temporal en Bitcoin OpenTimestamps.
