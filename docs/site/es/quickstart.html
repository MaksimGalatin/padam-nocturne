Inicio rápido y PADAM Studio

Desde cero hasta la interfaz web local de 10 pantallas con datos de demostración y plugins en un clic para clientes de IA.

Instalación

pip install padam-nocturne
# or with local model2vec embeddings (~30 MB):
pip install "padam-nocturne[embed]"
# optional L3 anchoring & ONNX injection detector:
pip install "padam-nocturne[l3,guard]"

Prueba inmediata en memoria demo (no toca memory.db)

python -m padam demo --studio crea ~/.padam/demo.db con preferencias firmadas, versiones, grafo causal, inyección retenida, anclaje L3 local y recibo de borrado.

python -m padam demo --studio
# quick CLI tour:
python -m padam remember "Answer in Russian, numbers first" --kind preference --importance 1.0
python -m padam recall "which language to use" --explain
python -m padam doctor

Clientes de IA, plugins y SDK

claude mcp add padam -- uvx padam-nocturne
# Multilingual Russian/Spanish/Chinese memory:
claude mcp add padam -e PADAM_EMBEDDER=model2vec -e PADAM_LOCAL_EMBED_MODEL=minishlab/potion-multilingual-128M -- uvx --from "padam-nocturne[embed]" padam-nocturne

Plugins en un clic (Claude Code, Cursor, Codex, Gemini CLI, Antigravity)

Manifiestos listos en .claude-plugin/, plugins/cursor, plugins/codex, plugins/gemini-cli y plugins/antigravity con comandos /recall, /remember y /profile.

LangChain, CrewAI, Vercel AI y Mastra

Conectores Python en integrations/ y SDK oficial en TypeScript packages/padam-client/.

Aplicación de escritorio y extensión

python -m padam desktop (más proyecto Tauri desktop-tauri/) y extensión Chrome/Edge con origen forzado external.

Qué incluyen las 10 pantallas de PADAM Studio

  • Resumen + Doctor de seguridad (interruptores débiles, PRAGMA quick_check, protección de claves).
  • Cronología, Búsqueda --explain y Máquina del tiempo (as_of).
  • Cola de revisión (Aprobar/Rechazar), Olvido + recibos JSON/HTML, Grafo canvas, Capa L3 y Ajustes.
  • CSP estricto con nonce, cero innerHTML (solo textContent), token #t= limpiado del historial, 4 idiomas y 2 temas.
