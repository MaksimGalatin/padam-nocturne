快速上手与 PADAM Studio

从零安装到使用独立演示库启动 10 屏可视化工作台，并一键接入主流 AI 客户端。

安装方式

pip install padam-nocturne
# or with local model2vec embeddings (~30 MB):
pip install "padam-nocturne[embed]"
# optional L3 anchoring & ONNX injection detector:
pip install "padam-nocturne[l3,guard]"

在独立演示库中立即体验（绝不触碰主库 memory.db）

运行 python -m padam demo --studio 会新建 ~/.padam/demo.db，包含主人签名偏好、版本演进链、因果图谱、被拦截的注入指令、本地 L3 快照与删除证明回执。

python -m padam demo --studio
# quick CLI tour:
python -m padam remember "Answer in Russian, numbers first" --kind preference --importance 1.0
python -m padam recall "which language to use" --explain
python -m padam doctor

AI 客户端一键插件与 SDK

claude mcp add padam -- uvx padam-nocturne
# Multilingual Russian/Spanish/Chinese memory:
claude mcp add padam -e PADAM_EMBEDDER=model2vec -e PADAM_LOCAL_EMBED_MODEL=minishlab/potion-multilingual-128M -- uvx --from "padam-nocturne[embed]" padam-nocturne

五大客户端一键插件（Claude Code / Cursor / Codex / Gemini CLI / Antigravity）

仓库内置 .claude-plugin/、plugins/cursor、plugins/codex、plugins/gemini-cli、plugins/antigravity 配置与 /recall、/remember、/profile 命令。

LangChain、CrewAI、Vercel AI 与 Mastra

integrations/ 目录提供 Python 适配器，packages/padam-client/ 提供官方 TypeScript SDK。

Windows 桌面安装程序 (Tauri v2) 与浏览器扩展

PADAM-Studio-Setup.exe（desktop/tauri/，20.97 MB，内置 Python 3.14.4 runtime/、系统托盘与拦截通知；首次运行如遇 SmartScreen 请点击“更多信息 -> 仍要运行”）及 python -m padam desktop 与浏览器扩展。

PADAM Studio 十大界面特性

  • 概览 + 安全体检医生（弱开关告警、PRAGMA quick_check、密钥保护状态、REST 令牌校验）。
  • 记忆时间线、可解释检索（--explain 拆分得分）与时光机（as_of 按历史日期查询）。
  • 审核队列（通过/拒绝）、单条遗忘与 JSON/HTML 删除回执、Canvas 关系图谱、L3 永恒层与设置。
  • 严格随机 nonce CSP，零 innerHTML（仅使用 textContent），地址栏一次性令牌 #t= 即刻擦除，支持 4 种语言与双主题。
