安全模型、数据围栏与红队实测

智能体写入并重新召回的记忆天然构成注入与泄露攻击面。结构性边界保证即使规则被绕过也守住底线。

五道结构性防线

1. 落盘前秘密掩码

20+ 种 API 密钥、Solana id.json / base58 / 12 与 24 词助记词（公开钱包地址保留可读）及 Luhn 银行卡在写入 SQLite 前替换为 [REDACTED:...]。

2. 注入拦截队列与 PADAM_STRICT=1

13 种语言提示词注入过滤器 + Chrome 扩展来源强制标为 external。开启 PADAM_STRICT=1 后所有智能体写入都必须经主人放行。

3. 128 位随机数据围栏

每次检索、时间线或画像返回均包裹在随机 32 位十六进制 nonce 标签中，防止内容伪造闭合标签。仅 padam_export 返回原始 JSON。

4. 主人签名的用户画像

identity 与 preference 记录携带 HMAC 主人签名；padam_profile 与 /profile 自动跳过未签名或篡改的记录。

5. 独立记录密钥与 Shamir 继承

protect-keys 通过 scrypt + AES-256-GCM + VACUUM 封装密钥。legacy split/combine 将口令拆分为 k-of-n 分片；panic 紧急销毁。
