# Security Challenge & Hall of Fame

All seven Red Team rounds published so far in [`docs/SECURITY_REVIEW.md`](docs/SECURITY_REVIEW.md) were generated by AI models working for the maintainer — **no external human audit has been completed yet**.

We welcome independent security researchers, AppSec engineers, and MCP developers to try breaking **PADAM · NOCTURNE**.

## In-Scope Targets

1. **Memory Poisoning / Quarantine Bypass:** Slip an external directive or owner-identity override past `padam_write` without triggering owner quarantine (`origin=external` or default mode).
2. **Secret Redaction (DLP) Bypass:** Store a realistic synthetic credential (`sk-`, `ghp_`, `AIza`, private key, seed phrase, Luhn card) that survives unmasked inside `memory.db` (`strings memory.db`).
3. **Data Fence Breakout:** Craft stored memory text that breaks out of the 128-bit random nonce data fence ([`docs/FENCING_SPEC.md`](docs/FENCING_SPEC.md)).
4. **Privilege / Isolation Flaw:** Allow an MCP agent to delete/forget records, read another `PADAM_USER`'s rows, or bypass `PADAM_STRICT=1`.

## How to Report

- **Non-critical bypass / new red-team test case:** Open a public Issue or PR adding the case to `redteam/` with reproduction steps.
- **Sensitive / high-severity vulnerability:** Email [`contact@codeofdigitaleternity.com`](mailto:contact@codeofdigitaleternity.com) (private disclosure; we publish a fix and credit you upon release).
