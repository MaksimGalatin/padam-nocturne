# План доведения до полного промышленного стандарта (оставшиеся этапы 3, 7, 8, 10)

Базовые этапы `1 -> 4 -> 5 -> 6 -> 2 -> 9` (адаптерный слой `MemoryAdapter`/`AgentAdapter`, удаление неинформативных критериев, относительная сложность `AS-055` и CI95, `git clone` по коммиту, 3 оси `M/S/A`, `SPEC.md`) реализованы в ветке `bench-standard-1711`.

Ниже — план оставшихся организационных и инфраструктурных этапов с оценкой трудозатрат:

| Этап | Описание работ | Зависимости / блокеры | Оценка трудозатрат |
|---|---|---|---|
| **Этап 3: Скрытый набор (Held-Out)** | Выделить 50% векторов атак и агентных задач в закрытый приватный репозиторий с ежеквартальной ротацией; публичный набор оставить для разработчиков, закрытый — для официального рейтинга против подгонки. | Приватный GitHub-репозиторий и CI-секреты. | 2–3 дня |
| **Этап 7: Ручная верификация статических находок** | Добавить к каждой статической находке сторонних систем ссылку на `file:line`, автоматический AST-контекст и флаг `human_verified` (`confirmed_by` / второй независимый парсер). | Прогон по всем целевым конкурентам и ручной аудит. | 3–4 дня |
| **Этап 8: Публикация доверенного ключа издателя** | Сгенерировать постоянную пару Ed25519 для официального CI-раннера (ключ в GitHub Secrets, **не** в коде), опубликовать `public_key_hex` на `aifa.works` / `codeofdigitaleternity.com`. | Доступ к секретам CI и сайтам (только по слову Папы). | 0.5 дня |
| **Этап 10: Публичный рейтинг (Leaderboard)** | Скрипт автогенерации статической витрины из подписанных JSON-прогонов (дата, версия, `commit_sha`, `files_scanned`, баллы по 3 осям `M/S/A`, доверительные интервалы). **На сайты не выносить до приёмки и слова Папы.** | Завершение этапов 3, 7, 8. | 1–2 дня |
