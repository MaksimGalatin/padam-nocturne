# AIFaSecurity — Эталонный бенчмарк защиты памяти ИИ-агентов (100 критериев, $0, без LLM)

**AIFaSecurity** — полностью автономный, детерминированный и бесплатный (`$0`, без вызова языковых моделей) бенчмарк из **100 исчисляемых экспериментов** (`AS-001`..`AS-100`) в 10 доменах безопасности:
1. Маскировка секретов до сохранения (DLP)
2. Защита от Prompt Injection
3. Целостность личности, правил и защита от подмены получателя платежа
4. Изоляция областей (`scope`), пользователей (`user_id`), команд и ролей
5. Криптографическое забвение, откат и битемпоральность
6. Устойчивость протокола MCP, валидация схем, ReDoS/SQLi/XSS/DoS
7. Шифрование, постквантовая готовность (`X-Wing`) и целостность хранения
8. Статический аудит репозиториев и веб-поверхностей (`repo` / `url`)
9. Качество поиска под атакой и наводнением памяти
10. Операционная готовность, воспроизводимость и печать `SHA-256`

## Быстрый старт

```bash
python benchmarks/aifa_security/run_aifa_sec.py
# Либо через CLI:
padam aifa-sec

# Проверка любого локального или публичного GitHub-репозитория (статически, без запуска кода):
padam aifa-sec --target repo --path https://github.com/owner/repo --no-write

# Проверка любого сайта или сервиса по URL:
padam aifa-sec --target url --path https://aifa.works --no-write

# Black-box проверка любого MCP stdio сервера:
padam aifa-sec --target mcp-cmd --path "python -m padam.mcp_server" --no-write
```
