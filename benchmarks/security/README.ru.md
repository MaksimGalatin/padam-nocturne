# Сравнение маскировки секретов: PADAM против Mem0 и Claude-Mem

Открытое, оффлайн (`$0`) и воспроизводимое сравнение маскировки секретов на сгенерированных фальшивых ключах и чистых (не-секретных) фразах.

## Что сравнивается
1. **PADAM Nocturne** — `padam.safety.redact` (та же функция, которую вызывает `Memory.remember` через `safety.clean`).
2. **Mem0** — 8 регулярных выражений из `mem0ai/mem0` (`integrations/codex-plugin/core/memory_core.py`, коммит `f1791daa86d469249c9b002f62644d58a1eb96a0`), перенесены в Python дословно без установки и запуска кода Mem0.
3. **Claude-Mem** — 42 встроенных шаблона + 4 общих шаблона (режимы `genericEnabled=False` и `genericEnabled=True` замерены отдельно) из `thedotmack/claude-mem` (`src/utils/redaction.ts`, коммит `f705e9b99601dd9ac03e2f77c5aded6ff3d9471b`), перенесены в Python дословно без запуска TypeScript.

## Набор данных
- **1 500 300 подстановок фальшивых ключей** на 5 фиксированных зёрнах (по `300 060` на зерно; 9 типов ключей × 20 реалистичных форм заметок/конфигов).
- **2 200 случаев секретов кошельков Solana** (64-байтные массивы `id.json`, ключи `base58`, сид-фразы BIP-39 на 12 и 24 слова).
- **200 вендорных ключей** (AWS `AKIA`, GitHub `ghp_`, Stripe `sk_live_`, JWT).
- **240 чистых фраз** (проверка ложных срабатываний: обычная проза со словами `key`/`token`/`password`/`ключ`/`токен`, хэши коммитов Git, UUID в ссылках, идентификаторы camelCase, имена моделей, публичный адрес Solana).

## Как воспроизвести одной командой
```bash
python benchmarks/security/compare_masking.py
```
Полный JSON-отчёт сохраняется в `benchmarks/security/results_masking_1611.json`.

## Ограничения и честность сравнения
- Шаблоны соперников перенесены в Python `re` вручную; JS lookbehind переменной длины (`(?<=PREFIX)VALUE`) в Claude-Mem переписан через захват префикса `(PREFIX)(VALUE)` с заменой на `\1<redacted .../>`, так как стандартный Python `re` требует фиксированной ширины lookbehind.
- Другие модули или облачные пайплайны Mem0 / Claude-Mem за пределами указанных файлов не проверялись и не запускались.
- Все ключи сгенерированы случайно по фиксированным зёрнам — настоящих секретов в наборе нет.
