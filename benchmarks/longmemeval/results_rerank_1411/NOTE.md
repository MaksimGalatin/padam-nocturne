# Замер опционального переранжирования (`PADAM_RERANK=1`, Б13)

- **Дата замера:** 14.11.2026 (`padam 0.4.18`, ветка `studio-1411`)
- **Набор LongMemEval-S (`--stride 5`):** 100 вопросов (94 с ответом + 6 без ответа), встроенный поиск, без LLM.
- **Сравниваемые прогоны (`w_pair = 0.30` / `w_base = 0.70`, `PADAM_RERANK_TOP = 30`):**
  - `stride5_off` (`PADAM_RERANK=0`, `595.1s`): `any@5 = 0.9468`, `any@10 = 0.9894`, `all@5 = 0.8191`, `all@10 = 0.8936`, `abstention all@10 = 0.8333`
  - `stride5_on_v2` (`PADAM_RERANK=1`, `554.0s`): `any@5 = 0.9574` (+1.06 п.п.), `any@10 = 0.9787` (-1.07 п.п.), `all@5 = 0.8191`, `all@10 = 0.8830` (-1.06 п.п.), `abstention all@10 = 1.0000`
  - Для сравнения, ранний черновой вес `0.45` (`stride5_on`, `275.8s`) просаживал `all@5` до `0.8085`, поэтому вес лексического второго прохода был снижен до `0.30`.
- **Чистая задержка на одном открытом `Memory` (500 записей, среднее по 25 запросам, `limit=10`):**
  - `PADAM_RERANK=0`: `72.46 ms` на вызов `recall()`
  - `PADAM_RERANK=1`: `148.21 ms` на вызов `recall()`
- **Вывод:** на LoCoMo (1 536 вопросов) `PADAM_RERANK=1` даёт устойчивый плюс по всем метрикам (`turn_any@5`: `0.5612 -> 0.5768`, `sess_any@5`: `0.9010 -> 0.9108`, multi-hop `sess_any@5`: `0.8404 -> 0.8794`), а на LongMemEval-S `--stride 5` поднимает `any@5` (+1.06 п.п.) ценой -1 вопроса на `@10` и вдвое большей задержки `recall()`. Поэтому `PADAM_RERANK` по умолчанию **выключен (`False`)** и включается пользователем в Настройках Studio или через `PADAM_RERANK=1`.
